# Globopersona – Frontend UI Redesign

This project is a frontend UI redesign built using React and CSS.

The goal of this project is to create a clean dashboard interface with sidebar navigation and multiple pages.

---

## Pages Implemented

- Dashboard  
- Campaigns  
- Create Campaign  
- Settings  

---

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS
