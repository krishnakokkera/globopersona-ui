1. Globopersona – Frontend UI Redesign

This project is a frontend UI redesign for the Globopersona dashboard, built using  React + Vite and CSS.

2.  Live Demo
https://globopersona-ui-kappa.vercel.app

3.  GitHub Repository
https://github.com/krishnakokkera/globopersona-ui

4. Features
- Dashboard layout
- Sidebar navigation
- Campaign pages
- Responsive UI
- Clean CSS styling

5. Technologies Used
- React (Vite)
- JavaScript
- HTML5
- CSS3

5. Installation & Run Locally

bash

git clone https://github.com/krishnakokkera/globopersona-ui.git
cd globopersona-ui
npm install
npm run dev
